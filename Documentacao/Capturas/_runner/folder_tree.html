FastBite — Estrutura de Pastas do Backend Backend/app/

Organização por camadas conforme arquitetura Clean Architecture / DDD (Cap. 4.1).
Domínio — modelos, máquinas de estado, enums
Aplicação — services, jobs, events, DTOs, outbox
Infraestrutura — repositórios, API GraphQL, Gateway

├── Domain/                          DOMÍNIO
│   ├── StateMachines/
│   │   ├── Orders/                  # OrderStateFactory + 8 estados
│   │   ├── Payments/                # PaymentStateFactory + 5 estados
│   │   └── Deliveries/              # DeliveryStateFactory + 5 estados
│   ├── Pricing/                     # PricingCalculator (funções puras)
│   └── Geo/                         # GeoMath (haversine)
├── Enums/                           DOMÍNIO  # OrderStatus, PaymentStatus, DeliveryStatus, ...
│
├── Services/                        APLICAÇÃO  # ~18 services: Order, Delivery, Payment, Cart, ...

├── Events/                          APLICAÇÃO  # DomainEventBroadcasted, CourierPositionUpdated
